![bullet_pp_2](/images/datasets__files__bullet_pp_2.png) The [FRUBASE database](http://pedroj.github.io/FRUBASE/).  
This is the page for the FRUBASE database, a huge dataset of fleshy fruit traits compiled from bibliographic references and my own work. Data are provided for more than 1000 plant species from all around the world.  
The dataset is available [in the Dryad repository](http://datadryad.org/handle/10255/dryad.46978). Updated versions of the file as well as supporting code and information are in the [Github repository](https://github.com/pedroj/FRUBASE).
